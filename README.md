# Reginald starter vault

This is an empty [Obsidan](https://obsidian.md) vault for starting or testing [Reginald](https://github.com/jamdev/reginald-agent). It includes the folder structure, task prompts, filing rules, and blank indexes. Your first research run starts with an empty set of briefs and run logs.

The starter vault tracks UK and EU legal and regulatory developments that matter to an imaginary fintech operating in the UK and the EU, including payments, digital assets, and consumer protection. Open the [topics index](Home.md#topic-index) to browse the areas it covers.

You can adapt the vault to another industry or jurisdiction. Edit the [persona file](Setup/Persona/Persona%20File.md) to describe the agent’s role and research priorities, update the [regulatory topics list](Setup/Taxonomy/Taxonomy%20-%20Regulatory%20topics.md) to define what it tracks, and revise the [research task](Setup/Tasks/Research%20new%20developments.md) to point it to the sources you want it to monitor.

## Use without Reginald

You could download and use this vault in Obsidian, and run the agents / tasks in [Setup/Tasks](Setup/Tasks/) in your harness of choice.   For example, you can run it within Claude Desktop.  This would allow you to run an entirely local copy without the need to install Reginald.
