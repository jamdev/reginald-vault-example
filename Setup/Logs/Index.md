# Run logs

One file per task run: `YYYY-MM-DD - task-name.md`. Reverse chronological.

Every run writes its own log here. Reginald deliberately raises **no content
event** for anything in this folder — run logs are bookkeeping, not
subscriber-facing content, so they never appear in `events list` and are never
emailed.
